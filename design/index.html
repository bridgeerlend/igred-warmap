IGRED Global Conflict Monitor

Three design directions for the map, each built on the same real data: one live day of incidents through the project's own pipeline, on cartography drawn from Natural Earth. Pick one and the map gets built in it.

  1. Direction A
    Dispatch

    Editorial. The map as the front page of a serious bulletin — warm paper, an academic serif, datelines, hairline rules. Reads as journalism.

  2. Direction B
    Instrument

    Technical. The map as a monitoring instrument — a visible graticule, incidents as reticles, calibrated ticks, every number monospaced. Reads as measurement.

  3. Direction C
    Atlas

    Monumental. Enormous display type against very small data, a stippled landmass, almost no interface. Reads as a gallery wall.

Each page has a light and dark mode, and responds to prefers-reduced-motion. Two things stand in for parts not yet built: the set of countries counted as actively at war is a placeholder until the UCDP register is connected, and the magenta points are illustrative — nothing has been verified by hand yet.
